# MangaMeYeah（マンガミーヤー）

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![Platform](https://img.shields.io/badge/Platform-Windows%2010%20%2F%2011%20(64--bit)-lightgrey.svg)](https://dotnet.microsoft.com/download/dotnet/8.0)
[![Status](https://img.shields.io/badge/Status-Under%20Active%20Development-orange.svg)](#現在のステータスとビルド方法)

伝説の Windows 用画像ビューアー **「MangaMeeya（マンガミーヤ）」の至高の操作感を目指して！**  
**多彩な画像形式、アーカイブに対応した高速ビューアー**  
.NET 8 / 64bit / WPF ネイティブでゼロから再構築し、現代の画像収集ワークフローや次世代フォーマット（WebP, AVIF 等）、X（旧Twitter）の多分割投稿画像の自動結合に対応した次世代コミック・画像ビューアーです。

> **[!NOTE]**  
> 本プロジェクトは **v0.3.5** を迎えました。  
> 設定の保存は MangaMeeya 互換の `MangaMeYeah.ini`（UTF-8）形式に対応し、ヘルプドキュメント（`F1` キー）も完備しています。  
> 各バージョンの詳細な実装経緯やバグ修正の歩みについては [HISTORY.md](HISTORY.md) をご覧ください。

## 開発の背景とコンセプト

20年以上前に登場し、今もなお愛され続ける伝説のビューアー「MangaMeeya」ですが、現代の PC 環境ではいくつかの大きな壁がありました：

1. **Shift_JIS 依存による文字化け**: 絵文字や多言語、特殊記号を含むファイル名・フォルダ名が正常に開けない。
2. **フォーマットごとのビューアー切り替え**: WebP や AVIF、各種 RAW 画像を閲覧するために別アプリを起動せざるを得ず、単一のビューアーで完結できない。

**MangaMeYeah**（名前の「Yeah!」は歓声・感動に由来し、もし漢字を当てるならば「漫画身弥」、読みは「マンガミーヤー」）は、MangaMeeya の比類なきマウス操作系と軽快さを完全に継承しながら、現代の環境でストレスなくすべての画像を単一のアプリで満喫できる「ストイックで爆速な純粋ビューアー」を目指して開発されています。

> **[!NOTE]**  
> 開発者は無用な争いを好まないため、「こんなのMangaMeeyaじゃない！」「MangaMeYeahなんてふざけた名前を付けやがって！」といった批判やご意見が多く寄せられた場合には、柔軟にプロジェクト名称を変更することもやぶさかではありません。ただし、いかなる場合でも開発自体を止めることはありません。  
> できる限り往年の MangaMeeya にあった多彩な機能を網羅・実装していく方針ですが、まずは作者自身が日常の作業や読書でヘビーユースしている機能から優先して実装を進めています。

## 主な機能と特徴（v0.3.5 現在）

### 1. MangaMeeya 準拠の至高のマウス操作体系
* **基本操作**:
  * **左クリック**: 次に進む
  * **右クリック**: 前に戻る
  * **コード操作（同時押し）**:
    * 右クリックを押しながら左クリック ＝ 1ページ進む
    * 左クリックを押しながら右クリック ＝ 1ページ戻る
  * **右クリック長押し（500ms）**: 「単ページ表示」と「2ページ（見開き）表示」の即座トグル（1枚ずれ補正にも最適）
  * **左クリック長押し（500ms）**: アプリケーションの即座終了
* **直感的なマウスジェスチャー（右ボタンドラッグ）**:
  * `[↓]`: 「縦サイズを揃える(2ページ表示用)」と「倍率固定(デフォルト)」のトグル
  * `[↑]`: フルスクリーンの切り替え
  * `[→]`: サムネイル一覧画面（ライトテーブル）の表示
  * `[←]`: ウィンドウサイズに合わせる
* **ルーペ機能 (`L` キー / 右クリック＋ホイール)**:
  * 見開き画像や高解像度イラストの細部をマウスカーソル追従でスムーズに部分拡大（125%〜800%）。
  * ルーペ使用中は画面上端のメニューバー／ツールバーの自動ポップアップが抑制され、快適に閲覧可能（環境設定で切替可能）。

### 2. X（旧Twitter）連結・多分割画像の自動パズル復元
1枚のイラストが複数枚に分割されて投稿された画像をエッジ色差（MAE）およびピアソン相関係数解析により自動検出し、結合表示します。
* **対応パターン**: 横2枚、縦2枚、横3枚、縦3枚、横4枚、縦4枚、縦横2×2（4枚組）
* **24通り全探索パズル復元アルゴリズム**:
  * タイムライン上での視覚トリック等により投稿時に意図的に並べ替えられ、ファイル名や連番と絵柄の並びが食い違ってバラバラになった 2×2 画像も、$4! = 24$ 通りの順列をミリ秒以下で総当たり照合し、本来の正しい [左上・右上・左下・右下] の組み合わせを自動復元して配置。
* **白余白・単色背景誤検出防止フィルター**:
  * 接合シームの色彩標準偏差判定（$\sigma \ge 7.0$）と方向別シーム相関スコアリングにより、白枠・黒枠や青空背景が続く連作イラストの誤結合を完全防止。
* **見開きアライメント自動維持**:
  * 見開き表示中に次の画像が連結画像の開始位置である場合、現在ページを自動で単ページ扱いにして連結グループの分断を防止。

### 3. 書庫・多重ネスト書庫（書庫内書庫）ダイレクト閲覧
* **主要書庫フォーマット完全対応**:
  * `.zip`, `.cbz`, `.rar`, `.cbr`, `.7z` 書庫ファイルを解凍せずに直接閲覧可能。
* **書庫内書庫（ネスト書庫）の完全直接展開閲覧**:
  * 書庫の中にさらに格納された書庫ファイル（`.zip` 内の `.zip` / `.rar` / `.cbz`）をディスクに展開することなく、メモリ上でオンデマンド展開してシームレスにブラウジング。
* **フォルダー内書庫の自動統合**:
  * フォルダー閲覧時に、同階層や配下に存在する書庫ファイルもサブフォルダーの1つとして透過的に結合して通しで閲覧可能。
* **macOS リソースフォーク完全自動無視**:
  * Mac 環境で作成された ZIP 内の `__MACOSX` フォルダーやメタデータファイルを自動的に除外。

### 4. 階層フォルダー再帰読み込み & 階層自然順グループソート
* **選べるサブフォルダー読み込み設定（環境設定 > 一般設定1）**:
  * 「ダイアログで確認」「常にサブフォルダも読み込む」「サブフォルダは読み込まない」の3モードに対応。
* **MangaMeYeah式 階層自然順グループソート**:
  * 親フォルダー直下の表紙画像を先頭に維持しつつ、配下のサブフォルダーや書庫を自然順で並べ、フォルダ内のファイル順序を維持したまま通しで閲覧可能。

### 5. 超高速・省メモリなサムネイル一覧画面（ライトテーブル）
* **行単位 UI 仮想化（`VirtualizingStackPanel`）**:
  * 数千枚を超える大規模フォルダでも瞬時に展開し、メモリ消費を最小限（200MB台）に抑制。
* **優先バックグラウンドデコード**:
  * 現在閲覧中のページ周辺から同心円状に優先してサムネイルを生成。
* **一括クイックセーブ**:
  * チェックボックスや Shift/Ctrl クリックで複数選択し、あらかじめ設定した 4 つの保存先フォルダ（QS1〜QS4）へワンクリックで一括振り分けコピー。

### 6. モーダレス画像情報ダイアログ（`I` キー / `Ctrl+I`）
* **モデルレス表示**:
  * ダイアログを開いたままビューアー操作（クリックやホイールスクロール）を継続可能。
* **キーボードナビゲーション連動**:
  * ダイアログにフォーカスがある状態でも `Home`（先頭ページ）、`End`（最終ページ）、`PageUp` / `PageDown`、矢印キー、`Space` でページ移動でき、表示内容（ファイル名・パス・解像度・色数等）がリアルタイムに自動追従更新。

### 8. 高度なキャッシュ・メモリ制御 & ポータブル INI 設計
* **LRU メモリ制御 & リサイズキャッシュ**:
  * 指定したキャッシュ上限（初期値 2GB）に基づき、古いキャッシュビットマップを先行解放して PC のリソースを圧迫しません。
* **先読みスレッド優先度スライダー**:
  * バックグラウンド先読みデコードスレッドの優先度（0:最低 〜 4:最高、デフォルト2:通常）を環境設定から調整可能。UIの操作応答性を最優先に維持。
* **兄弟フォルダーのバックグラウンド先読みキャッシュ**:
  * 閲覧中に前後のフォルダーパスを非同期に解決・保持し、フォルダー端での遷移を高速化。
* **MangaMeeya 互換 INI ファイル（`MangaMeYeah.ini`）による設定保存**:
  * アプリケーション直下の `MangaMeYeah.ini`（UTF-8）にすべての設定、レジューム位置、クイックセーブ先を保存。
  * レジストリを汚さずポータブルに運用可能で、メモ帳などのテキストエディタでも直感的に設定を確認・編集可能。
* **複数起動を禁止する（Named Pipe IPC）**:
  * ON にすると、エクスプローラー等から別の画像を開いた際に新しいウィンドウを作らず、既存の MangaMeYeah ウィンドウにファイルを転送して最前面化。
* **マルチモニター・フルスクリーン復元**:
  * フルスクリーンで終了した場合は次回起動時もフルスクリーンかつ該当モニターで復元起動。
* **公式ヘルプドキュメントシステム（`F1` キー）**:
  * アプリケーション内で `F1` キーを押すかメニューの `ヘルプ(H)` から、詳細な操作説明や環境設定リファレンスをいつでも参照可能。

## ショートカットキー一覧

| キー | 動作 |
| :--- | :--- |

## 配布パッケージとビルド方法

### 1. 配布パッケージ（GitHub Releases）
- **ポータブル ZIP 版（推奨）**:
  - 解凍するだけでそのまま使える自己完結型パッケージ。レジストリを使用せず、設定は同階層の `MangaMeYeah.ini` に保存されます。
- **インストーラー版（Setup.exe）**:
  - スタートメニュー登録、デスクトップショートカット作成、右クリック「MangaMeYeahで開く」コンテキストメニュー登録をまとめて行いたい方向け。

### 2. ソースコードからのビルド
```bash
git clone https://github.com/emmmanime/MangaMeYeah.git
cd MangaMeYeah
dotnet run --project src/MangaMeYeah -c Release
```
