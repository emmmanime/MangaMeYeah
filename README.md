# MangaMeYeah

**MangaMeeya** の操作感・高速性を継承しつつ、Windows 11 環境および現代の画像収集ワークフロー（`discord-oneclick` / `name2win` / 将来の `ThumbsPlus 8J` 代替アプリ連携）に最適化した次世代・純粋画像ビューア。

## 設計コンセプト・方針

1. **ストイックで爆速な純粋ビューア**
   - ファイラー・カタログ管理機能は「ThumbsPlus 8J 代替アプリ」側へ分離・連携し、ビューア本体は余計な並行ブラウザ画面を持たず、開いた瞬間に画像を表示しマウスひとつで自在に操れる「MangaMeeya の手触り」に特化する。
2. **技術スタック**
   - **UI / メインフレームワーク**: C# (.NET 8+) + WPF
   - **ネイティブ / 高速処理・プラグインブリッジ**: 必要に応じて **Rust** モジュール（DLL / サブプロセス）を組み込むハイブリッド構成
   - **Susie プラグイン (`.spi` / `.sph`) 対応**: 現代の標準フォーマット（JPEG, PNG, WebP, AVIF, ZIP, RAR, 7z, PDF 等）は 64bit ネイティブで高速処理しつつ、レトロフォーマット等のための「切り札」として Susie プラグインにも対応。
3. **独自強化機能（アイデアノートより）**
   - **関連画像のジャンプ**: ファイル名の連続プレフィックス（作者・シリーズ等）を解析し、同一プレフィックスの先頭（`Home`）／末尾（`End`）へジャンプする機能。
   - **画像連結表示**: X（旧Twitter）等の最大4枚分割投稿に対応した連結表示（4枚横・4枚縦・2×2・3枚横・3枚縦）。
   - **macOS リソースフォーク等の完全除外**: `__MACOSX`、`._*`、`.DS_Store` 等のノイズを自動無視。
   - **動画再生連携**: フォルダ・書庫内の動画ファイル（`.mp4`, `.webm` 等）をシームレスに別窓／オーバーレイ再生。
   - **Everything 連携によるお気に入りリンク修復**: ファイル名＋アーカイブハッシュ値を用いて移動・リネーム後のリンク切れを自動追跡・修復。

## ディレクトリ構成（初期）

- `tools/` : 本家 `MangaMeeya.exe` および `MangaMeeya.ini` のバイナリリソース・設定解析スクリプト群
- `docs/` : 抽出されたリソースデータ（JSON）および解析ドキュメント
