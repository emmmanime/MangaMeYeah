# MangaMeYeah（マンガミーヤー）

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![Platform](https://img.shields.io/badge/Platform-Windows%2010%20%2F%2011%20(64--bit)-lightgrey.svg)](https://dotnet.microsoft.com/download/dotnet/8.0)
[![Status](https://img.shields.io/badge/Status-Under%20Active%20Development-orange.svg)](#現在のステータスとビルド方法)

伝説の Windows 用画像ビューワー **「MangaMeeya（マンガミーヤ）」** の至高の操作感と高速性を現代に復刻。  
.NET 8 / 64bit / WPF ネイティブでゼロから再構築し、現代の画像収集ワークフローや次世代フォーマット（WebP, AVIF 等）、X（旧Twitter）の多分割投稿画像の自動結合に対応した次世代コミック・画像ビューワーです。

> **[!NOTE]**  
> 本プロジェクトは **v0.3.2** を迎えました。  
> 各バージョンの詳細な実装経緯やバグ修正の歩みについては [HISTORY.md](HISTORY.md) をご覧ください。

## 開発の背景とコンセプト

20年以上前に登場し、今もなお愛され続ける伝説のビューワー「MangaMeeya」ですが、現代の PC 環境ではいくつかの大きな壁がありました：

1. **Shift-JIS 依存による文字化け**: 絵文字や多言語、特殊記号を含むファイル名・フォルダ名が正常に開けない。
2. **フォーマットごとのビューワー切り替え**: WebP や AVIF、各種 RAW 画像を閲覧するために別アプリを起動せざるを得ず、単一のビューワーで完結できない。

**MangaMeYeah**（名前の「Yeah!」は歓声・感動に由来し、もし漢字を当てるならば「漫画身弥」、読みは「マンガミーヤー」）は、MangaMeeya の比類なきマウス操作系と軽快さを完全に継承しながら、現代の環境でストレスなくすべての画像を単一のアプリで満喫できる「ストイックで爆速な純粋ビューワー」を目指して開発されています。

> **[!NOTE]**  
> 開発者は無用な争いを好まないため、「こんなのMangaMeeyaじゃない！」「MangaMeYeahなんてふざけた名前を付けやがって！」といった批判やご意見が多く寄せられた場合には、柔軟にプロジェクト名称を変更することもやぶさかではありません。ただし、いかなる場合でも開発自体を止めることはありません。  
> できる限り往年の MangaMeeya にあった多彩な機能を網羅・実装していく方針ですが、まずは作者自身が日常の作業や読書でヘビーユースしている機能から優先して実装を進めています。

## 主な機能と特徴（v0.3.2 現在）

### 1. MangaMeeya 準拠の至高のマウス操作体系
* **基本操作**:
  * **左クリック**: 次に進む
  * **右クリック**: 前に戻る
  * **コード操作（同時押し）**:
    * 右クリックを押しながら左クリック ＝ 1ページ進む
    * 左クリックを押しながら右クリック ＝ 1ページ戻る
  * **右クリック長押し（500ms）**: 「単ページ表示」と「2ページ（見開き）表示」の即座トグル（1枚ずれ補正にも最適）
  * **左クリック長押し（500ms）**: アプリケーションの即座終了
* **直感的なマウスジェスチャー（右ボタンドラッグ）**:
  * `[↓]`: 「縦サイズを揃える(2ページ表示用)」と「倍率固定(デフォルト)」のトグル
  * `[↑]`: フルスクリーンの切り替え
  * `[→]`: サムネイル一覧画面（ライトテーブル）の表示
  * `[←]`: ウィンドウサイズに合わせる
* **ルーペ機能 (`L` キー / 右クリック＋ホイール)**:
  * 見開き画像や高解像度イラストの細部をマウスカーソル追従でスムーズに部分拡大（125%〜800%）。
  * ルーペ使用中は画面上端のメニューバー／ツールバーの自動ポップアップが抑制され、快適に閲覧可能（環境設定で切替可能）。

### 2. X（旧Twitter）連結・多分割画像の自動パズル復元
1枚のイラストが複数枚に分割されて投稿された画像をエッジ色差（MAE）およびピアソン相関係数解析により自動検出し、結合表示します。
* **対応パターン**: 横2枚、縦2枚、横3枚、縦3枚、横4枚、縦4枚、縦横2×2（4枚組）
* **24通り全探索パズル復元アルゴリズム**:
  * 投稿順やファイル名順でバラバラ（シャッフル）になった 2×2 画像も、$4! = 24$ 通りの順列をミリ秒以下で総当たり照合し、最適な [左上・右上・左下・右下] の組み合わせを自動復元して配置。
* **AI連作イラスト誤検出防止フィルター**:
  * 青空や海など単色・グラデーション背景が続く連作イラストでの誤判定を防ぐエッジ色彩分散および接合シーム相関判定（Pearson Correlation）を搭載。

### 3. 書庫ファイル直接閲覧 & 階層フォルダー再帰読み込み & ページレジューム機能
* **主要書庫フォーマット完全対応**:
  * `.zip`, `.cbz`, `.rar`, `.cbr`, `.7z` 書庫ファイルを解凍せずに直接閲覧可能。
  * サブフォルダー（階層構造）を持つ書庫やフォルダーも自動的に再帰探索し、全画像を通しで閲覧可能。
  * オンデマンド・ストリーミング展開＆LRUメモリキャッシュにより、大容量書庫でも待機時間ゼロで高速展開。
* **終了時・移動時の表示画像（レジューム位置）の自動復元**:
  * フォルダおよび書庫ファイルごとに、最後に開いていたページを自動的に記憶・次回起動時に復元。
* **透過的なフォルダ・書庫巡回**:
  * マウスのサイドボタンや `Ctrl+左右` キー等で、同一階層の「次の書庫／前の書庫／フォルダ」を透過的に連続ブラウジング。

### 4. 超高速・省メモリなサムネイル一覧画面（ライトテーブル）
* **行単位 UI 仮想化（`VirtualizingStackPanel`）**:
  * 4,000枚を超える大規模フォルダでも瞬時に展開し、メモリ消費を最小限（200MB台）に抑制。
* **優先バックグラウンドデコード**:
  * 現在閲覧中のページ周辺から同心円状に優先してサムネイルを生成。
* **一括クイックセーブ**:
  * チェックボックスや Shift/Ctrl クリックで複数選択し、あらかじめ設定した 4 つの保存先フォルダ（QS1〜QS4）へワンクリックで一括振り分けコピー。

### 5. 現代フォーマットの完全網羅 & 完全 Unicode 対応
* **対応フォーマット**:
  * JPEG, PNG, GIF, BMP, WebP, AVIF, HEIC, TIFF
  * デジタル一眼 RAW 形式（CR2, CR3, NEF, ARW, DNG, ORF, RAF, RW2）
* **完全 Unicode 対応**:
  * 日本語、英語はもちろん、あらゆる多言語・絵文字・特殊記号を含むパスを文字化けなく高速処理。

### 6. 高度なキャッシュ・メモリ制御 & 環境設定
* **LRU メモリ制御**:
  * 指定したキャッシュ上限（初期値 2GB）に基づき、古いキャッシュビットマップを先行解放して PC のリソースを圧迫しません。
* **インテリジェント先読み**:
  * 閲覧方向（進む・戻る）に応じたバックグラウンド先読みデコードにより、待ち時間ゼロのページめくりを実現。
* **Windows ネイティブ色選択ダイアログ**:
  * 環境設定（一般設定2）の背景色・本棚背景色設定にカラーピッカーを完備。
* **マルチモニター・フルスクリーン復元**:
  * フルスクリーンで終了した場合は次回起動時もフルスクリーンかつ該当モニターで復元起動。上部メニューの表示見切れも解消。

## ショートカットキー一覧

| キー | 動作 |
| :--- | :--- |
| `Space` | 1ページ表示 / 2ページ表示の切り替え |
| `\` / `\|` | 見開き方向（右開き / 左開き）の切り替え |
| `Z` | 縦横どちらか合わせる |
| `X` | ウィンドウサイズに合わせる |
| `C` | 原寸サイズで表示 |
| `V` | 倍率固定表示 |
| `B` | 指定スケール表示 |
| `N` | 画像サイズに合わせる |
| `+` / `-` | ズームイン / ズームアウト（拡大・縮小） |
| `L` | ルーペ（虫眼鏡）表示の切り替え |
| `A` / `H` | サムネイル表示（4列 / 8列） |
| `Home` / `End` | 最初のページへ / 最後のページへ |
| `F11` | フルスクリーン切り替え |
| `Ctrl + I` | 画像情報ダイアログ（Home/Endでテキスト移動、色数オンデマンド解析） |
| `Esc` | ルーペ解除 / フルスクリーン解除 / サムネイル画面を閉じる |

## 現在のステータスとビルド方法

現在はソースコードからのビルド・検証を行っています。

### リポジトリのクローンと実行
```bash
git clone https://github.com/emmmanime/MangaMeYeah.git
cd MangaMeYeah
dotnet run --project src/MangaMeYeah -c Release
```

### ポータブル単一バイナリの発行
```bash
dotnet publish src/MangaMeYeah -c Release -r win-x64 --self-contained false
```
* 初回起動時にエクスプローラーの右クリックメニュー（「MangaMeYeahで開く」）が自動登録されます（`設定 ＞ レジストリ関連設定` からいつでも解除・再登録可能）。
* バイナリ（ZIP）での一般リリース配布は、基本機能が安定した段階で GitHub Releases にて公開を予定しています。
