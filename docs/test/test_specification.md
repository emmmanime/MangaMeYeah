# MangaMeYeah! テスト仕様書 (Test Specification)

本書は、**MangaMeYeah!** の品質検証、リグレッション防止、および機能網羅率（MangaMeeya 互換度）を管理するためのテスト仕様書です。
MangaMeeya (v7.4b) の全メニュー項目をベースとし、現行バージョン（v0.3.5）での実装状況（【実装済み】／【未実装】／【代替・現代化】）を網羅的にマッピングしています。

## 2. コア機能・非機能テストケース

### 2-1. フォーマット・デコード検証テスト
- [x] **WebP**: アニメーションWebP、可逆・非可逆WebPが劣化なく開けること。
- [x] **AVIF**: 10bit/12bit HDR AVIF 画像が正常展開されること。
- [x] **RAW**: 各社（CR2/CR3, NEF, ARW, DNG, RAF, RW2）のプレビューが瞬時に抽出表示されること。
- [x] **DDS**: DirectX テクスチャ形式（BC1〜BC7, DXT1〜5）が正しく描画されること。
- [ ] **SVG**: （v0.4.0 予定）ベクター画像が拡大してもジャギーなく鮮明にレンダリングされること。

### 2-2. 書庫・階層構造検証テスト
- [x] **ネスト書庫**: Zip の中に格納された CBZ や RAR 内の Zip が一時ファイルなしでメモリ展開されること。
- [x] **macOS 不要メタデータ**: `__MACOSX/` や `._filename.jpg` が画像リストから完全に除外されること。
- [x] **階層自然順グループソート**: 親直下の表紙 → サブフォルダ自然順の階層関係が常に保たれること。

### 2-3. 自動パズル復元（X 連結画像）検証テスト
- [x] **4枚組グリッド**: タイムライン上で順序がシャッフルされた4枚画像が $4! = 24$ 通り探索で正しく2×2結合されること。
- [x] **白余白誤検出防止**: 純白・単色背景の独立した別画像が結合判定されないこと（`seamStdDev >= 7.0`）。

### 2-4. パフォーマンス・メモリ検証テスト
- [x] **連続ページめくり負荷**: 1000枚のフォルダを高速連打でめくってもメモリリークおよび UI フリーズが発生しないこと。
- [x] **メモリ上限制御**: `MaxCacheMemoryMB`（2048MB）到達時に古いキャッシュが LRU で正しく解放されること。
