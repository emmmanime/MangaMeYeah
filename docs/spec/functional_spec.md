# MangaMeYeah! 機能設計書 (Functional Specification)

本書は、次世代高速画像ビューアー **MangaMeYeah!** の全体機能、各サブシステムの動作仕様、データフロー、および境界条件を詳細に定義する機能仕様書です。

---

## 1. システム全体概要と設計方針

### 1-1. 目的
20年以上前に登場し、コミック・画像ビューアーの金字塔となった「MangaMeeya」の比類なきマウス操作系と軽快さを、現代の Windows 11 / 64-bit / .NET 8 環境に忠実に再現・再構築し、現代の画像フォーマット（WebP, AVIF, RAW 等）や収集ワークフローに対応した高速純粋ビューアーを提供する。

### 1-2. コア設計方針
1. **0ms ページめくり**: ディスク I/O や画像デコードによる引っかかりを一切排除する非同期先読みおよびメモリ管理。
2. **完全 Unicode 対応**: Shift_JIS 制約を撤廃し、絵文字・多言語・ロングパスでも破綻なく動作。
3. **レジストリ非依存（ポータブル優先）**: 設定は実行ファイル同階層の `MangaMeYeah.ini`（UTF-8）に完全集約。
4. **ストイックな純粋ビューアー**: 肥大化した重厚なデータベースを持たず、メモリ消費を最小限に抑制。

## 2. ウィンドウおよびプロセスライフサイクル仕様

### 2-1. 単一インスタンス制御 (Single Instance IPC)
- **設定項目**: `SingleInstance`（`環境設定 > その他設定 > 複数起動を禁止する`）
- **動作仕様**:
  - `SingleInstance = true` の場合、起動時にミューテックス `Global\MangaMeYeah_SingleInstance_Mutex` を取得照合する。
  - 既に先行プロセスが実行中の場合、Named Pipe (`\\.\pipe\MangaMeYeah_IpcPipe`) 経由で起動引数（開くべきファイル/フォルダパス）を先行プロセスに送信し、後続プロセスは即時終了する。
  - 先行プロセスはパイプからパスを受信すると、即座に該当パスを開き、ウィンドウを前面化（アクティブ化）する。
  - `SingleInstance = false` の場合は多重起動を許可する。

### 2-2. ウィンドウ配置・マルチモニター復元仕様
- **設定項目**: `RememberWindowPosition`, `IsFullScreen`
- **動作仕様**:
  - 終了時のウィンドウ幅・高さ・左上座標（`WindowLeft`, `WindowTop`）を `MangaMeYeah.ini` に保存。
  - 起動時、保存座標が現在の仮想スクリーン領域（全モニターの結合バウンディングボックス）に含まれているかを検証し、モニター切断等で見失うのを防止。
  - フルスクリーン状態で終了した場合は、次回起動時も該当モニター上でフルスクリーンとして起動。

### 2-3. タイトルバー・キャプション動的更新仕様
- **書式**:
  - 空フォルダ状態: `MangaMeYeah! - [{フォルダ名}] (画像なし)`
  - 単ページ表示時: `MangaMeYeah! - [{フォルダ名}] ({現在ページ}/{総ページ}) {ファイル名} [{幅}x{高さ}]`
  - 見開き表示時: `MangaMeYeah! - [{フォルダ名}] ({開始ページ}-{終了ページ}/{総ページ}) {ファイル名1} / {ファイル名2}`
  - 全閉じ状態: `MangaMeYeah!`
- **サブフォルダパス表示設定**:
  - `ShowSubfolderInCaption = true` の場合は絶対フルパスを表示。`false` の場合はフォルダ名（ベース名）のみ表示。

## 3. ファイル・フォルダー・書庫の読み込み仕様

### 3-1. 階層関係とサブフォルダ読み込み
| 関係 | 構造例 | 動作・設定 |
| :--- | :--- | :--- |
| **フォルダ内フォルダ** | `Vol1/Ch1/01.jpg` | **サブフォルダ読み込みモード**（確認ダイアログ / 常に読み込む / 読み込まない） |
| **フォルダ内書庫** | `Vol1/Special.zip` | `IncludeArchivesInSubfolders = true` の場合、書庫をサブフォルダとして透過的に結合 |
| **書庫内フォルダ** | `Vol1.zip` 内の `Ch1/01.jpg` | 書庫標準仕様として常にシームレスに結合（展開待機なし） |
| **書庫内書庫 (ネスト書庫)** | `Vol1.zip` 内の `Bonus.cbz` | `IncludeNestedArchives = true` の場合、メモリ上で直接ストリーム展開 |

### 3-2. MangaMeYeah!式 階層自然順グループソート
- **ソート規則**:
  1. 親フォルダ直下に存在する表紙画像（`Cover.jpg` 等）を必ず先頭（Index 0）に配置。
  2. サブフォルダおよび内包書庫を自然順（1, 2, 10...）でグループ化。
  3. 各グループ内ではファイル名の自然順序を厳格に保持。
- **除外対象**:
  - `__MACOSX`, `._*`（macOS リソースフォーク）
  - `.DS_Store`, `Thumbs.db`, `desktop.ini`

### 3-3. 並列（兄弟）フォルダの自動切り替えと 0ms 移行
- **動作仕様**:
  - 現在フォルダの最終ページに到達した状態で `Next`（左クリック）を実行すると、親フォルダ内の次の兄弟フォルダ（例: `第1巻` → `第2巻`）へ自動遷移。
  - 先頭ページで `Prev`（右クリック）を実行すると、前の兄弟フォルダの最終ページへ自動遷移。
  - 遷移の引っかかりをゼロにするため、閲覧中にバックグラウンドスレッドが前後の兄弟フォルダパスを先行探索してメモリ上にキャッシュする。

## 4. 表示エンジン仕様

### 4-1. ページ表示モード
- **単ページ表示 (SinglePage)**: 1画面に1画像を表示。
- **見開き表示 (TwoPage)**: 1画面に2画像を並列表示。
  - **見開き方向**: 右開き（コミック標準：右が1ページ目、左が2ページ目）／左開き（写真集・左綴じ標準：左が1ページ目、右が2ページ目）。
  - **自動見開き (AutoSpread)**: 画像の縦横比（アスペクト比）を判定し、横長画像（見開きスキャン等）が来た場合は自動的に1画面全面表示へ切り替え、縦長画像に戻ると2ページ並列に戻す。

### 4-2. スケールモードと画像補間
- **原寸表示 (ActualSize)**: 100% ピクセル等倍表示。
- **ウィンドウサイズに合わせる (FitWindow)**: ウィンドウ枠内に収まるよう縦横比を維持して拡大・縮小。
- **幅を合わせる (FitWidth)**: ウィンドウの横幅いっぱいに拡大・縮小（縦スクロール用）。
- **高さを合わせる (FitHeight)**: ウィンドウの高さに合わせる。
- **縮小専用 (ShrinkOnly)**: 画像がウィンドウより大きい場合のみ縮小し、小さい画像は拡大しない。
- **補間フィルター**:
  - `Lanczos3` (PhotoSauce.MagicScaler / SkiaSharp): モアレやジャギーのない最高品位補間。
  - `Bilinear`: 高速描画。
  - `NearestNeighbor`: ドット絵・拡大時のシャープ表示。

## 5. キャッシュおよびメモリ制御仕様

### 5-1. 独立2系統キャッシュアーキテクチャ
```
[ディスク/書庫]
    ├─► 本編ビューアー用 (PageCacheEngine)
    │     ├─ 原寸 / リサイズ済みビットマップ
    │     ├─ 展開キャッシュ数 (初期値 32枚)
    │     └─ 容量上限 (初期値 2048 MB)
    │
    └─► サムネイル一覧用 (ThumbnailItemViewModel)
          ├─ 約 220px の超軽量サムネイル
          └─ 本編キャッシュ枠を一切破棄しない
```

### 5-2. 先読みパイプライン
- **進む方向先読み数**: デフォルト 6枚（連結画像検出のため4枚以上推奨）。
- **戻る方向先読み数**: デフォルト 4枚。
- **先読みスレッド優先度**:
  - 0: 最低（CPU アイドル時のみ実行）
  - 2: 通常（標準）
  - 4: 最高（先行デコード最優先）
- **メモリ上限と LRU 破棄**:
  - デコード済みビットマップの合計サイズが `MaxCacheMemoryMB` を超えた場合、最も現在位置から離れたページのキャッシュから順に破棄。

## 6. X（旧Twitter）連結・多分割画像の自動パズル復元仕様

### 6-1. 対象パターン
- 横2枚（見開きイラスト）
- 縦2枚（4コマ漫画、全身画）
- 横3枚 / 縦3枚（パノラマ、縦長漫画）
- 横4枚 / 縦4枚（超ワイド、キャラクターシート）
- 2列×2行（4枚組グリッド投稿）

### 6-2. 24通り全探索アルゴリズム
- 4枚の連番画像に対し、$4! = 24$ 通りの配置順列を瞬時に生成。
- 隣接境界（シーム）の画素色差（MAE）およびテクスチャ相関を総当たり照合。
- タイムライン演出等のために投稿時に意図的にシャッフルされた画像でも、元の正しいイラスト配置を自動復元。

### 6-3. 誤検出防止フィルター
- **エッジ標準偏差判定**: シーム近傍の色彩標準偏差 `seamStdDev >= 7.0` を要求。純白・単色背景の独立した別イラスト同士が誤って結合されるのを完全防止。
- **見開きずれ自動補正**: 見開き表示の途中で連結画像の先頭が現れた場合、前ページを単ページ表示化して見開きスロットのずれを自動解消。

### 6-4. 連結画像検出のオン/オフ設定・永続化と `connected_folders.txt` 自動有効化 (v0.4.1 / v0.4.2)
- **メニューアクセス**: メインメニュー「表示(_V)」最下部および右クリックコンテキストメニュー「表示(_V)」最下部に `連結画像検出(_C)` を配置。
- **設定の即時保存**: トグル切り替え時に `MangaMeYeah.ini` の `[Config]` セクションにある `AutoDetectConnectedImages`（0: 無効, 1: 有効）に即時永続保存。
- **対象フォルダー設定ファイル (`connected_folders.txt`)**:
  - 実行ファイルと同階層に配置される `connected_folders.txt` にフォルダーパス（または `*` / `?` ワイルドカード）を1行1件で記述すると、該当フォルダー配下を開いた際に自動的に `連結画像検出` が ON になる。
  - `環境設定 -> 読込・見開き` タブの `対象フォルダー設定ファイルを開く...` ボタンから既定のテキストエディタで直接編集可能。

## 7. 操作系仕様

### 7-1. マウスクリック・ホイール操作
- **左クリック**: 1ページ（または見開き2ページ）進む。
- **右クリック**: 1ページ（または見開き2ページ）戻る。
- **右クリック長押し (500ms)** / **`Space` キー**: 単ページ ⇔ 見開き表示のトグル切替。一時的に単ページ表示に切り替えた後は、次ページ/前ページへ移動すると自動的に元の2ページ見開き表示へ復帰する。
- **左クリック長押し (500ms)**: アプリケーション即時終了。
- **コード操作（同時押し）**:
  - 右押しながら左クリック: 見開き表示中でも強制的に1ページ進む。
  - 左押しながら右クリック: 見開き表示中でも強制的に1ページ戻る。
- **左ボタンドラッグ**: パン（スクロール移動）。
- **マウスホイール回転**:
  - 縦スクロール可能な状態（画像の縦サイズがビューポートを超えている場合）では、上端（`0`）および下端（`ScrollableHeight`）でピタッと止まり、ホイール回転による前後ページへの自動遷移は行わない（MangaMeeya 互換）。
- **外部でのファイル移動・削除時の安全動作 (MangaMeeya 互換)**:
  - 閲覧中のファイルが外部操作で移動・削除された場合、1回目の左/右クリックではエラーダイアログを出さず画面も変化させずに内部リストから欠損ファイルを除外し、2回目のクリックで次または前の有効な画像へスムーズに遷移する。

### 7-2. マウスジェスチャー
- **右ボタンドラッグ**: マウスの移動軌跡から方向ストロークを検出。
- **主なジェスチャー**:
  - `↑`: フルスクリーン切り替え
  - `↓`: `縦サイズを揃える(2ページ表示用)` ⇔ `原寸サイズで表示` のトグル切替（`MangaMeeya.ini` の `FilpScaleMode=1` 互換）
  - `←`: `縦横どちらか合わせる`
  - `→`: `サムネイル表示(カスタム)`
  - `↑←` (`↖`): クイックセーブ 1
  - `↑→` (`↗`): クイックセーブ 2
  - `↓←` (`↙`): クイックセーブ 3
  - `↓→` (`↘`): クイックセーブ 4

### 7-3. ルーペ（拡大鏡）
- **表示形態**: 円形 / 四角形ルーペ。
- **高解像度再デコード**: ルーペを開いた瞬間に元画像のフル解像度ビットマップをデコードし、`LoupeVisualBrush` (`Stretch="Fill"`) によって設定倍率（`LoupeScale`、初期値 `2.0x`）で鮮明に拡大描画する。
- **マウス中心配置と画面端・画像端クランプ**:
  - マウスクリック位置がルーペ枠の中心に来るよう配置。
  - `画面外にはみ出さないようにする` (`LoupeClampToScreen`) が有効な場合、外枠が画面端で止まると同時に、ルーペ内の拡大領域も画像端でクランプされる。ルーペ直径が画面サイズを超える場合は、クリック位置が画面中央より上/下・左/右かに応じて画像の上端/下端・左端/右端をルーペ端に揃える。

### 7-4. キーボードナビゲーション & 関連画像並びジャンプ
- **ページナビゲーション**:
  - `→` / `PageDown`: 次のページへ進む
  - `←` / `PageUp`: 前のページへ戻る
  - `Home`: 作品/フォルダー全体の先頭ページへ
  - `End`: 作品/フォルダー全体の最終ページへ
  - `Ctrl + →` / `Ctrl + ←`: 次／前の兄弟フォルダーへ移動
  - `Shift + ↓` / `Shift + ↑`: 1ページ進む／戻る
- **関連画像並びジャンプ (`Ctrl + Home` / `Ctrl + End`)**:
  - **`Ctrl + Home` (`関連画像並びの先頭へ`)**:
    - 現在位置が関連画像並びの途中・末尾の場合: **現在の関連画像並びの先頭（1枚目）** へジャンプ（OSD: `関連画像並びの先頭: X (n/m)`）。
    - すでに先頭にいる場合: **1つ前の関連画像並びの先頭** へジャンプ（OSD: `前の関連画像並びの先頭: X (n/m)`、連打で高速巻き戻し）。
    - 最初のグループの1ページ目にいる場合: OSD `最初の関連画像並びの先頭です: X (1/m)` を表示。
  - **`Ctrl + End` (`関連画像並びの最後尾へ`)**:
    - 現在位置が関連画像並びの先頭・途中の場合: **現在の関連画像並びの最後尾** へジャンプ（OSD: `関連画像並び最後尾: X (n/m)`）。
    - すでに最後尾にいる場合: **次の関連画像並びの先頭** へジャンプ（OSD: `次の関連画像並び: X (n/m)`、連打で次グループへスキップ）。
    - 最後のグループの最終ページにいる場合: OSD `最後の関連画像並びの最後尾です: X (m/m)` を表示。
  - **自動プレフィックス抽出規則**:
    - Twitter Downloader 形式: `{Prefix}-{TweetID}-...` の最初のハイフン前
    - 角括弧形式: `[グループ名]`、`【グループ名】`
    - アンダースコア区切り形式: `group_01` 等の最終アンダースコア前
    - 数字連番形式: `image001` 等の末尾数値トリム
    - 比較は大文字小文字を区別せず実施（OrdinalIgnoreCase）。

### 7-5. 最下行シークバー（ツールバー）とメニュー・シークバースタイル切替 (v0.4.2)
- **最下行シークバー (`BottomSeekBarBorder`)**:
  - 左側ボタン群：`フォルダツリー表示`、`前のフォルダ(書庫)へ`、`前に戻る`、`再生/停止 (スライドショー)`、`次に進む`、`次のフォルダ(書庫)へ`、`ファイルを開く`、`最初のページへ`。
  - 中央：ページシークトラックバー (`SeekBarSlider`) ＋ ページ番号表示ボックス (`1/546`、クリックで指定ページへジャンプ)。
  - 右側ボタン群：`最終ページへ`、`見開き方向切替`、`ルーペ表示`、`サムネイル表示(1画面)`、`ブックリスト表示`、`フルスクリーン切替`。
  - 全画面表示時にマウスカーソルを画面下端へ移動するとポップアップ表示され、同時に縦横スクロールバーも表示される（MangaMeeya 互換）。
- **メニュー・シークバースタイル切替 (`レトロ` / `モダン`)**:
  - **レトロモード (MangaMeeya 互換)**: フォントに `MS UI Gothic` (9pt / `12px`, `TextFormattingMode="Display"`) を使用し、MangaMeYeah! 独自拡張メニュー項目を非表示化。`ヘルプ(H)` メニューの最上部に `画像情報(I)...` を配置し、シークバーをクラシック 3D スタイルで描画。
  - **モダンモード (MangaMeYeah! 拡張)**: モダンフォントと全拡張メニュー項目を表示し、`ヘルプ(H)` メニューの最上部に `マニュアル・操作説明(M)...` を配置。シークバーは MangaMeYeah! ロゴカラー（ダークネイビー `#0F172A`、シアン `#00D2FF`、ゴールド `#FFBE0B`）で描画。

## 8. サムネイル一覧画面（ライトテーブル）仕様

## 9. 設定管理とレジストリ連携仕様

### 9-1. `MangaMeYeah.ini` と表示位置記憶 (方式A)
- アプリケーション本体と同じフォルダに UTF-8（BOMなし）で保存。
- **フォルダーおよび書庫内の表示位置記憶 (`RememberPagePosition`、方式A)**:
  - デフォルトは **OFF**（常に先頭ページから開く）。
  - **ON** の場合は、フォルダーや書庫ごとに前回閉じたページ位置を `[Resume]` セクションに記憶して再開するが、**最終ページまで読み切ったフォルダー/書庫については記憶をリセットし、次回は先頭ページから開く**。
- **書庫のみ開く (`OpenArchivesOnly`、初期値 OFF)**:
  - ON にすると、フォルダー内（および書庫内）のバラ画像を除外し、アーカイブファイル（`.zip`, `.cbz`, `.rar`, `.cbr`, `.7z`）のみを読み込む（Patreon 等のダウンロードフォルダで圧縮ファイルと展開済み画像が混在している場合の重複表示を防止）。

### 9-2. エクスプローラー連携 (HKCU)
- 管理者権限不要で、現在のユーザーのレジストリ（`HKCU\Software\Classes`）にコンテキストメニューを登録：
  - フォルダ右クリック / フォルダ背景右クリック / ファイル右クリックすべて **`マンガミーヤーで開く`** に統一。
