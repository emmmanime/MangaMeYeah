# MangaMeYeah! 機能設計書 (Functional Specification)

本書は、次世代高速画像ビューアー **MangaMeYeah!** の全体機能、各サブシステムの動作仕様、データフロー、および境界条件を詳細に定義する機能仕様書です。

---

## 1. システム全体概要と設計方針

### 1-1. 目的
20年以上前に登場し、コミック・画像ビューアーの金字塔となった「MangaMeeya」の比類なきマウス操作系と軽快さを、現代の Windows 11 / 64-bit / .NET 8 環境に忠実に再現・再構築し、現代の画像フォーマット（WebP, AVIF, RAW 等）や収集ワークフローに対応した高速純粋ビューアーを提供する。

### 1-2. コア設計方針
1. **0ms ページめくり**: ディスク I/O や画像デコードによる引っかかりを一切排除する非同期先読みおよびメモリ管理。
2. **完全 Unicode 対応**: Shift_JIS 制約を撤廃し、絵文字・多言語・ロングパスでも破綻なく動作。
3. **レジストリ非依存（ポータブル優先）**: 設定は実行ファイル同階層の `MangaMeYeah.ini`（UTF-8）に完全集約。
4. **ストイックな純粋ビューアー**: 肥大化した重厚なデータベースを持たず、メモリ消費を最小限に抑制。

## 2. ウィンドウおよびプロセスライフサイクル仕様

### 2-1. 単一インスタンス制御 (Single Instance IPC)
- **設定項目**: `SingleInstance`（`環境設定 > その他設定 > 複数起動を禁止する`）
- **動作仕様**:
  - `SingleInstance = true` の場合、起動時にミューテックス `Global\MangaMeYeah_SingleInstance_Mutex` を取得照合する。
  - 既に先行プロセスが実行中の場合、Named Pipe (`\\.\pipe\MangaMeYeah_IpcPipe`) 経由で起動引数（開くべきファイル/フォルダパス）を先行プロセスに送信し、後続プロセスは即時終了する。
  - 先行プロセスはパイプからパスを受信すると、即座に該当パスを開き、ウィンドウを前面化（アクティブ化）する。
  - `SingleInstance = false` の場合は多重起動を許可する。

### 2-2. ウィンドウ配置・マルチモニター復元仕様
- **設定項目**: `RememberWindowPosition`, `IsFullScreen`
- **動作仕様**:
  - 終了時のウィンドウ幅・高さ・左上座標（`WindowLeft`, `WindowTop`）を `MangaMeYeah.ini` に保存。
  - 起動時、保存座標が現在の仮想スクリーン領域（全モニターの結合バウンディングボックス）に含まれているかを検証し、モニター切断等で見失うのを防止。
  - フルスクリーン状態で終了した場合は、次回起動時も該当モニター上でフルスクリーンとして起動。

### 2-3. タイトルバー・キャプション動的更新仕様
- **書式**:
  - 空フォルダ状態: `MangaMeYeah! - [{フォルダ名}] (画像なし)`
  - 単ページ表示時: `MangaMeYeah! - [{フォルダ名}] ({現在ページ}/{総ページ}) {ファイル名} [{幅}x{高さ}]`
  - 見開き表示時: `MangaMeYeah! - [{フォルダ名}] ({開始ページ}-{終了ページ}/{総ページ}) {ファイル名1} / {ファイル名2}`
  - 全閉じ状態: `MangaMeYeah!`
- **サブフォルダパス表示設定**:
  - `ShowSubfolderInCaption = true` の場合は絶対フルパスを表示。`false` の場合はフォルダ名（ベース名）のみ表示。

### 2-4. OSD (On-Screen Display) 通知仕様
- **表示トリガー**: ページめくり、拡大縮小、回転、見開きモード切替、クイックセーブ実行、エラー発生時。
- **表示形態**: キャンバス左上（または中央）に半透明の黒背景・白文字プレートを一時表示（フェードアウト）。

## 3. ファイル・フォルダー・書庫の読み込み仕様

### 3-1. 階層関係とサブフォルダ読み込み
| 関係 | 構造例 | 動作・設定 |
| :--- | :--- | :--- |
| **フォルダ内フォルダ** | `Vol1/Ch1/01.jpg` | **サブフォルダ読み込みモード**（確認ダイアログ / 常に読み込む / 読み込まない） |
| **フォルダ内書庫** | `Vol1/Special.zip` | `IncludeArchivesInSubfolders = true` の場合、書庫をサブフォルダとして透過的に結合 |
| **書庫内フォルダ** | `Vol1.zip` 内の `Ch1/01.jpg` | 書庫標準仕様として常にシームレスに結合（展開待機なし） |
| **書庫内書庫 (ネスト書庫)** | `Vol1.zip` 内の `Bonus.cbz` | `IncludeNestedArchives = true` の場合、メモリ上で直接ストリーム展開 |

### 3-2. MangaMeYeah!式 階層自然順グループソート
- **ソート規則**:
  1. 親フォルダ直下に存在する表紙画像（`Cover.jpg` 等）を必ず先頭（Index 0）に配置。
  2. サブフォルダおよび内包書庫を自然順（1, 2, 10...）でグループ化。
  3. 各グループ内ではファイル名の自然順序を厳格に保持。
- **除外対象**:
  - `__MACOSX`, `._*`（macOS リソースフォーク）
  - `.DS_Store`, `Thumbs.db`, `desktop.ini`

### 3-3. 並列（兄弟）フォルダの自動切り替えと 0ms 移行
- **動作仕様**:
  - 現在フォルダの最終ページに到達した状態で `Next`（左クリック）を実行すると、親フォルダ内の次の兄弟フォルダ（例: `第1巻` → `第2巻`）へ自動遷移。
  - 先頭ページで `Prev`（右クリック）を実行すると、前の兄弟フォルダの最終ページへ自動遷移。
  - 遷移の引っかかりをゼロにするため、閲覧中にバックグラウンドスレッドが前後の兄弟フォルダパスを先行探索してメモリ上にキャッシュする。

## 4. 表示エンジン仕様

### 4-1. ページ表示モード
- **単ページ表示 (SinglePage)**: 1画面に1画像を表示。
- **見開き表示 (TwoPage)**: 1画面に2画像を並列表示。
  - **見開き方向**: 右開き（コミック標準：右が1ページ目、左が2ページ目）／左開き（写真集・左綴じ標準：左が1ページ目、右が2ページ目）。
  - **自動見開き (AutoSpread)**: 画像の縦横比（アスペクト比）を判定し、横長画像（見開きスキャン等）が来た場合は自動的に1画面全面表示へ切り替え、縦長画像に戻ると2ページ並列に戻す。

### 4-2. スケールモードと画像補間
- **原寸表示 (ActualSize)**: 100% ピクセル等倍表示。
- **ウィンドウサイズに合わせる (FitWindow)**: ウィンドウ枠内に収まるよう縦横比を維持して拡大・縮小。
- **幅を合わせる (FitWidth)**: ウィンドウの横幅いっぱいに拡大・縮小（縦スクロール用）。
- **高さを合わせる (FitHeight)**: ウィンドウの高さに合わせる。
- **縮小専用 (ShrinkOnly)**: 画像がウィンドウより大きい場合のみ縮小し、小さい画像は拡大しない。
- **補間フィルター**:
  - `Lanczos3` (PhotoSauce.MagicScaler / SkiaSharp): モアレやジャギーのない最高品位補間。
  - `Bilinear`: 高速描画。
  - `NearestNeighbor`: ドット絵・拡大時のシャープ表示。

## 5. キャッシュおよびメモリ制御仕様

### 5-1. 独立2系統キャッシュアーキテクチャ
```
[ディスク/書庫]
    ├─► 本編ビューアー用 (PageCacheEngine)
    │     ├─ 原寸 / リサイズ済みビットマップ
    │     ├─ 展開キャッシュ数 (初期値 32枚)
    │     └─ 容量上限 (初期値 2048 MB)
    │
    └─► サムネイル一覧用 (ThumbnailItemViewModel)
          ├─ 約 220px の超軽量サムネイル
          └─ 本編キャッシュ枠を一切破棄しない
```

### 5-2. 先読みパイプライン
- **進む方向先読み数**: デフォルト 6枚（連結画像検出のため4枚以上推奨）。
- **戻る方向先読み数**: デフォルト 4枚。
- **先読みスレッド優先度**:
  - 0: 最低（CPU アイドル時のみ実行）
  - 2: 通常（標準）
  - 4: 最高（先行デコード最優先）
- **メモリ上限と LRU 破棄**:
  - デコード済みビットマップの合計サイズが `MaxCacheMemoryMB` を超えた場合、最も現在位置から離れたページのキャッシュから順に破棄。

## 6. X（旧Twitter）連結・多分割画像の自動パズル復元仕様

### 6-1. 対象パターン
- 横2枚（見開きイラスト）
- 縦2枚（4コマ漫画、全身画）
- 横3枚 / 縦3枚（パノラマ、縦長漫画）
- 横4枚 / 縦4枚（超ワイド、キャラクターシート）
- 2列×2行（4枚組グリッド投稿）

### 6-2. 24通り全探索アルゴリズム
- 4枚の連番画像に対し、$4! = 24$ 通りの配置順列を瞬時に生成。
- 隣接境界（シーム）の画素色差（MAE）およびテクスチャ相関を総当たり照合。
- タイムライン演出等のために投稿時に意図的にシャッフルされた画像でも、元の正しいイラスト配置を自動復元。

### 6-3. 誤検出防止フィルター
- **エッジ標準偏差判定**: シーム近傍の色彩標準偏差 `seamStdDev >= 7.0` を要求。純白・単色背景の独立した別イラスト同士が誤って結合されるのを完全防止。
- **見開きずれ自動補正**: 見開き表示の途中で連結画像の先頭が現れた場合、前ページを単ページ表示化して見開きスロットのずれを自動解消。

## 7. 操作系仕様

### 7-1. マウスクリック操作
- **左クリック**: 1ページ（または見開き2ページ）進む。
- **右クリック**: 1ページ（または見開き2ページ）戻る。
- **右クリック長押し (500ms)**: 単ページ ⇔ 見開き表示のトグル切替。
- **左クリック長押し (500ms)**: アプリケーション即時終了。
- **コード操作（同時押し）**:
  - 右押しながら左クリック: 見開き表示中でも強制的に1ページ進む。
  - 左押しながら右クリック: 見開き表示中でも強制的に1ページ戻る。
- **左ボタンドラッグ**: パン（スクロール移動）。

### 7-2. マウスジェスチャー
- **右ボタンドラッグ**: マウスの移動軌跡から8方向（または4方向2ストローク）を検出。
- **クイックセーブ**:
  - `↑→`: クイックセーブ 1
  - `→↓`: クイックセーブ 2
  - `↓←`: クイックセーブ 3
  - `←↑`: クイックセーブ 4

### 7-3. ルーペ（拡大鏡）
- **表示形態**: 円形 / 矩形ルーペ。
- **操作**: 右ボタンドラッグ中、または `Space` / ルーペキー押下中にカーソル位置を原寸または指定倍率（2x〜8x）で拡大プレビュー。ホイール回転で拡大率を変更。

## 8. サムネイル一覧画面（ライトテーブル）仕様

### 8-1. 表示・スクロール
- `A` キーまたはメニューから表示切り替え。
- **UI 仮想化**: `VirtualizingStackPanel` による行単位仮想化で、1万枚超の大規模フォルダでも 200MB 以下のメモリで軽快に動作。
- **優先バックグラウンド生成**: 現在ページ周辺から同心円状に優先デコード。

### 8-2. 複数選択と一括操作
- `Ctrl` / `Shift` クリック、またはチェックボックスで複数画像を選択。
- 選択画像を一括でクイックセーブフォルダへ移動/コピー。

## 9. 設定管理とレジストリ連携仕様

### 9-1. `MangaMeYeah.ini`
- アプリケーション本体と同じフォルダに UTF-8（BOMなし）で保存。
- レジューム情報（`[Resume]` セクション）に各フォルダ/書庫の閲覧終了ページ番号を永続記録。

### 9-2. エクスプローラー連携 (HKCU)
- 管理者権限不要で、現在のユーザーのレジストリ（`HKCU\Software\Classes`）にコンテキストメニューを登録：
  - フォルダ右クリック: 「MangaMeYeah!で開く(&M)」
  - フォルダ背景右クリック: 「このフォルダをMangaMeYeah!で開く(&M)」
  - ファイル右クリック: 「MangaMeYeah!で開く(&M)」
