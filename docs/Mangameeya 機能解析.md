# Mangameeya 機能解析

## はじめに

この文書は Mangameeya の代替となるアプリ（**MangaMeYeah**）開発をするための資料です。できる限り Mangameeya の機能を網羅・整理し、現在の Windows 11 との互換性を高めるとともに、ファイラー／カタログ管理（ThumbsPlus 8J 代替）との役割分担を明確化するのが目的です。

---

## Windows 11互換機能

### ファイル名・パス仕様

- **予約文字**:
  - `\` （円マーク／バックスラッシュ）
  - `/` （スラッシュ）
  - `:` （コロン）
  - `*` （アスタリスク）
  - `?` （クエスチョンマーク）
  - `"` （ダブルクォーテーション）
  - `<` （小なり記号）
  - `>` （大なり記号）
  - `|` （パイプライン／縦棒）
- **文字数制限（MAX_PATH 260文字制限の解消）**:
  - 従来の Win32 アプリ（MangaMeeya 含む）ではドライブ名・フォルダー階層・ファイル名・拡張子を合わせた全体長が原則 260 文字以内（`MAX_PATH`）に制限されていた。
  - 新アプリ（.NET 8+）では ロングパス（`\\?\` プレフィックス相当および Windows 11 の長大パス）に標準対応し、深い階層の書庫や長い投稿タイトルでもエラーなく開けるようにする。
- **Unicode（UTF-8 / UTF-16 サロゲートペア・絵文字・環境依存文字）完全対応**:
  - Shift_JIS (CP932) 外の Unicode 文字（中国語・韓国語圏の漢字、絵文字、記号、`〜` 波ダッシュ問題等）を含むフォルダ名・ファイル名・ZIP内エントリ名を文字化けせず読み込む。
- **macOS 等の不要メタデータ自動除外**:
  - アーカイブ内およびフォルダ内の `__MACOSX/` フォルダ、`._*`（AppleDouble リソースフォーク）、`.DS_Store`、`Thumbs.db`、`desktop.ini` を自動的に除外する。
- **高DPI（スケーリング）・マルチモニター対応**:
  - Per-Monitor DPI Aware に対応し、4K 等の高解像度ディスプレイでも UI 文字と画像描画（ドットバイドット原寸表示含む）がぼやけないようにする。

### 1. マウスジェスチャ設定（公式デフォルト）

### 3. 実用カスタム設定（えままま氏 使用例・カスタムプリセット）

ThumbsPlus 8J による画像カタログ管理や大量画像の超高速選別を目的として最適化された、開発者自身の実運用カスタム設定です。将来の「カスタム設定プリセット」の実装ベースとなります。

#### (1) カスタム・マウスジェスチャ（クイックセーブ連携）
4方向の2ストローク（左上・右上・左下・右下）に **クイックセーブ1〜4** を割り当て、閲覧しながら右ドラッグ一筆書きで即座に選別フォルダーへ振り分ける構成です。

| **`←`** | **縦横どちらか合わせる** | ウィンドウ全体に収まるよう自動調整（追加登録） |
| **`→`** | サムネイル表示(カスタム) | 13列×144px サムネイル一覧（デフォルト維持） |

### 4. MangaMeYeah! での互換方針

1. **デフォルト設定の優先採用**:
   - 初期起動時の標準マウスジェスチャおよびキーバインドは、**MangaMeeya 7.4b の公式デフォルト**に準拠します。
2. **新機能キーの衝突回避**:
   - v0.4.0 で追加された「関連画像（クリエイター別）ジャンプ」には、MangaMeeya デフォルトで完全な空き枠であった **`Ctrl + Home`**（先頭へ）および **`Ctrl + End`**（最後尾へ）を採用し、既存の操作系と 100% 衝突しない設計を確立しています。
3. **ワンクリック・プリセット切替の計画**:
   - 「MangaMeeya デフォルトプリセット」と「えままま氏カスタムプリセット（クイックセーブ特化）」をメニューから瞬時に切り替えられる機能を今後のロードマップで提供します。
