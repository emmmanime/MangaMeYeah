# キャッシュ仕様とパフォーマンス調整 (Cache & Performance)

MangaMeYeah は、大容量の画像フォルダーや巨大な書庫ファイルでも待機時間ゼロでページをめくれるよう、効率的なオンデマンド・キャッシュおよび非同期先読みエンジンを内蔵しています。

---

## 1. 独立した2系統のキャッシュアーキテクチャ

MangaMeYeah のキャッシュシステムは、**本編ビューアー用** と **サムネイル一覧用** で明確に分離されています。

```
[ディスク/書庫]
    │
    ├─► (閲覧時) ──► 本編ビューアー用キャッシュ (PageCacheEngine)
    │                 ├─ 原寸 / 画面最適化デコードビットマップ
    │                 ├─ 展開キャッシュ数 (デフォルト 32枚)
    │                 └─ キャッシュ制限容量 (デフォルト 2048 MB)
    │
    └─► (一覧時) ──► サムネイル用キャッシュ (ThumbnailItemViewModel)
                      ├─ 220px前後の軽量リサイズ画像
                      └─ 本編の32枚キャッシュ枠を一切消費しない
```

### なぜ分離されているのか？
一般的なビューアーでは、サムネイル一覧を開いて何百枚もの縮小画像を読み込むと、直前まで読んでいた本編の高画質ビットマップがメモリから追い出されてしまい、本編に戻った際に再デコードの引っかかりが発生します。  
MangaMeYeah では、サムネイル画像を本編キャッシュとは別の軽量ビューモデル側で直接保持するため、**何千枚のサムネイルを一気に読み込んでも、本編の前後ページ（32枚枠）が一切破棄されず、爆速のページめくり性能が完全に維持されます**。

---

## 2. キャッシュ設定項目とチューニング

`環境設定 > キャッシュ設定` で調整可能な各項目の意味とおすすめ設定です。

### 展開キャッシュ数 (デフォルト: 32枚)
- **意味**: デコード済みの無圧縮ビットマップ画像をメモリ内に保持する最大枚数です。
- **推奨**: 普段使いであれば **32 〜 64枚** で十分快適です。ページを前後に激しく往復する読書スタイルの場合は、搭載RAM容量に応じて 128枚 などに増やすとより快適になります。

### リサイズキャッシュ有効 (デフォルト: ON)
- **意味**: ON の場合、ディスプレイの解像度に合わせて最適縮小したビットマップをキャッシュします。
- **効果**: 4K〜8Kなどの超高解像度イラストを閲覧する際、メモリ消費量を劇的に抑制し、GPU描画負荷を軽減します。

### 先読み枚数（進む方向 / 戻る方向）(デフォルト: 4〜6枚)
- **意味**: 現在閲覧しているページから、先回りしてバックグラウンドでデコードしておく枚数です。
- **重要ポイント**:
  - **自動連結画像検出を有効にする場合**: X（旧Twitter）の4分割画像や2×2画像を検出するために、**進む方向の先読み枚数は「4枚以上」** を設定してください（デフォルトで4枚以上に設定されています）。

### 先読みスレッド優先度 (デフォルト: 2 通常)
スライダーで 0（最低）〜 4（最高）の5段階で指定できます。

| レベル | 優先度名 | 特徴とおすすめ用途 |
| :---: | :--- | :--- |
| **0** | **最低** (Lowest) | UIスレッド（マウス操作やアニメーション）を最優先。CPU負荷を抑えたい省電力ノートPCや、ゲーム起動中の裏での閲覧に最適。 |
| **1** | **やや低** (BelowNormal) | 読書操作への干渉を確実に防ぎつつ、スムーズに先読みします。 |
| **2** | **通常** (Normal) ★推奨 | 一般的なマルチコアPCに最適。先読みとUIのバランスが最も優れています。 |
| **3** | **やや高** (AboveNormal) | 高速スクロール時に先読みをより前倒しで進めたい場合に有効。 |
| **4** | **最高** (Highest) | CPUリソースを最大限に注ぎ込み、次ページを極限まで最速でメモリ展開します。 |

### キャッシュ制限容量 (デフォルト: 2048 MB)
- キャッシュ全体の合計推定メモリ使用量がこの上限（例: 2GB）を超えた場合、閲覧位置から最も遠い古いキャッシュから自動的にガベージコレクション（LRU破棄）されます。
- `0 MB` を指定するとメモリ制限を行いません。
