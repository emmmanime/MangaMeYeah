# 基本操作ガイド (Basic Controls)

MangaMeYeah! は、片手マウスだけで快適かつ高速にマンガやイラストを読み進められる MangaMeeya 伝統のマウス操作体系を忠実に再現しています。

---

## 1. マウスクリック操作

| 操作 | 動作 | 備考 |
| :--- | :--- | :--- |
| **左クリック** | 次のページに進む | 見開き表示時は2ページ進みます |
| **右クリック** | 前のページに戻る | 見開き表示時は2ページ戻ります |
| **右クリック長押し** (500ms) | **単ページ ⇔ 見開き表示のトグル切替** | 表紙で1枚ずれてしまった見開きを瞬時に補正可能 |
| **左クリック長押し** (500ms) | **アプリケーションの即時終了** | ウィンドウの「×」ボタンまでカーソルを運ぶ必要がありません |
| **左ボタンドラッグ** | 画像のパン（スクロール）移動 | 画面より大きい画像や拡大表示中の閲覧に便利です |

### コード操作（同時押し）
ボタンを離さずにもう一方のボタンをクリックすることで、1ページ単位の微調整が瞬時に行えます。
- **右クリックを押しながら左クリック**: **1ページ進む**（見開き表示中でも強制的に1ページだけ送る）
- **左クリックを押しながら右クリック**: **1ページ戻る**（見開き表示中でも強制的に1ページだけ戻す）
- **右クリックを押しながら中クリック**: コンテキストメニューを表示

## 2. マウスジェスチャー（右ボタンドラッグ）

右ボタンを押したままマウスを素早く動かして離すことで、各種コマンドを直感的に実行できます。

| 方向 | コマンド名 | 動作 |
| :---: | :--- | :--- |
| **↓** (下) | **縦サイズを揃える** | 「縦サイズを揃える(複数枚表示用)」と「倍率固定(デフォルト)」をトグル切り替え |
| **↑** (上) | **フルスクリーン切替** | 全画面表示と通常ウィンドウ表示をトグル切り替え |
| **→** (右) | **サムネイル一覧表示** | ライトテーブル風のサムネイル一覧オーバーレイを表示 |
| **←** (左) | **ウィンドウサイズに合わせる** | 画像をウィンドウの幅・高さに合わせてフィット表示 |

---

## 3. ルーペ機能（部分拡大鏡）

見開きマンガの細かなフキダシや、高解像度イラストの細部をマウスカーソル追従でスムーズに拡大観察できます。

- **ルーペのON / OFF**: `L` キー または **中クリック**
- **拡大率の変更**:
  - `右クリックを押しながらホイール回転`
  - またはルーペ表示中に `↑` / `↓` キー（125% 〜 800%）
- **ルーペ半径（サイズ）の変更**:
  - ルーペ表示中に `←` / `→` キー（60px 〜 360px）
- **上部メニューバーのポップアップ自動抑止**:
  - ルーペ使用中に画面上端付近へカーソルを運んでも、メニューバーやツールバーが意図せずポップアップして邪魔にならないよう自動制御されます（環境設定で変更可能）。

## 4. キーボードショートカット一覧

| キー | 動作 |
| :--- | :--- |
| **Right** / **PageDown** | 次のページに進む |
| **Left** / **PageUp** | 前のページに戻る |
| **Home** | 先頭ページへジャンプ |
| **End** | 最終ページへジャンプ |
| **Space** | 1ページ表示 ⇔ 2ページ（見開き）表示のトグル |
| **\\** / **\|** | 右開き ⇔ 左開きのトグル切替 |
| **Z** | スケールモード: 縦横どちらか合わせる |
| **X** | スケールモード: ウインドウサイズに合わせる |
| **C** | スケールモード: 原寸サイズで表示 |
| **V** | スケールモード: 縦サイズを揃える(2ページ表示用) |
| **F** | フルスクリーン切り替え |
| **T** | サムネイル一覧（ライトテーブル）の開閉 |
| **I** | **画像情報ウィンドウの表示**（モーダレス・Home/End対応） |
| **F1** | ユーザーズマニュアル（本ヘルプ）の表示 |
| **Ctrl + O** | 画像ファイルを開く |
| **Ctrl + Shift + O** | フォルダを開く |
| **Ctrl + C** | 現在表示中の画像をクリップボードにコピー |
| **Ctrl + 1〜4** | クイックセーブスロット 1〜4 へ現在ページを瞬時に保存 |
| **Shift + 左右キー** | 10%ステップのジャンプ移動 |
| **Ctrl + 左右キー** | 前／次のフォルダー・書庫へジャンプ |
