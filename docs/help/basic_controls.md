# 基本操作ガイド (Basic Controls)

MangaMeYeah! は、片手マウスだけで快適かつ高速にマンガやイラストを読み進められる MangaMeeya 伝統のマウス操作体系を忠実に再現しています。

---

## 1. マウスクリック操作

| 操作 | 動作 | 備考 |
| :--- | :--- | :--- |
| **左クリック** | 次のページに進む | 見開き表示時は2ページ進みます |
| **右クリック** | 前のページに戻る | 見開き表示時は2ページ戻ります |
| **右クリック長押し** (500ms) | **単ページ ⇔ 見開き表示のトグル切替** | 表紙で1枚ずれてしまった見開きを瞬時に補正可能（次/前ページへ移動すると自動的に2ページ見開きへ復帰） |
| **左クリック長押し** (500ms) | **アプリケーションの即時終了** | ウィンドウの「×」ボタンまでカーソルを運ぶ必要がありません |
| **左ボタンドラッグ** | 画像のパン（スクロール）移動 | 画面より大きい画像や拡大表示中の閲覧に便利です |
| **ホイール回転** | 縦スクロール移動 / ページ送り | 縦長画像等で縦スクロールが可能な状態では、**上端（`0`）および下端でピタッと止まり**、意図せず前後ページへ遷移しない MangaMeeya 互換仕様です |

### コード操作（同時押し）
ボタンを離さずにもう一方のボタンをクリックすることで、1ページ単位の微調整が瞬時に行えます。
- **右クリックを押しながら左クリック**: **1ページ進む**（見開き表示中でも強制的に1ページだけ送る）
- **左クリックを押しながら右クリック**: **1ページ戻る**（見開き表示中でも強制的に1ページだけ戻す）
- **右クリックを押しながら中クリック**: コンテキストメニューを表示

## 2. マウスジェスチャー（右ボタンドラッグ）

右ボタンを押したままマウスを素早く動かして離すことで、各種コマンドを直感的に実行できます。

| 方向 | コマンド名 | 動作 |
| :---: | :--- | :--- |
| **↓** (下) | **縦サイズを揃える** | 「縦サイズを揃える(2ページ表示用)」と「原寸サイズで表示」をトグル切り替え（`MangaMeeya.ini` の `FilpScaleMode=1` 互換） |
| **↑** (上) | **フルスクリーン切替** | 全画面表示と通常ウィンドウ表示をトグル切り替え |
| **→** (右) | **サムネイル一覧表示** | ライトテーブル風のサムネイル一覧オーバーレイを表示 |
| **←** (左) | **ウィンドウサイズに合わせる** | 画像をウィンドウの幅・高さに合わせてフィット表示 |

## 3. ルーペ機能（部分拡大鏡）

見開きマンガの細かなフキダシや、高解像度イラストの細部をマウスカーソル追従でスムーズに拡大観察できます。

- **ルーペのON / OFF**: `L` キー または **中クリック**
- **拡大率の変更**:
  - `右クリックを押しながらホイール回転`
  - またはルーペ表示中に `↑` / `↓` キー（125% 〜 800%）
- **ルーペ半径（サイズ）の変更**:
  - ルーペ表示中に `←` / `→` キー（60px 〜 360px）
- **上部メニューバーのポップアップ自動抑止**:
  - ルーペ使用中に画面上端付近へカーソルを運んでも、メニューバーやツールバーが意図せずポップアップして邪魔にならないよう自動制御されます（環境設定で変更可能）。

## 5. 関連画像並びジャンプ (`Ctrl + Home` / `Ctrl + End`)

ファイル名のプレフィックス（Twitter Downloader の `{Creator}-{TweetID}-...`、`[グループ名]`、`prefix_01` 等）から同一シリーズの「関連画像並び」を自動判別し、グループ単位で高速に頭出し・スキップできる機能です。

- **`Ctrl + Home` (`移動(J) -> 関連画像並びの先頭へ(H)`)**:
  - 現在位置が関連画像並びの**途中または末尾**にある場合：**現在の関連画像並びの先頭（1枚目）**へジャンプします（OSD: `関連画像並びの先頭: X (n/m)`）。
  - すでに現在の関連画像並びの**先頭**にいる場合：**1つ前の関連画像並びの先頭**へジャンプします（OSD: `前の関連画像並びの先頭: X (n/m)`）。そのまま `Ctrl + Home` を連打することで、前のグループへと次々に巻き戻すことができます。
  - フォルダー全体の最初のグループの先頭にいる場合：`最初の関連画像並びの先頭です: X (1/m)` と通知されます。
- **`Ctrl + End` (`移動(J) -> 関連画像並びの最後尾へ(E)`)**:
  - 現在位置が関連画像並びの**先頭または途中**にある場合：**現在の関連画像並びの最後尾**へジャンプします（OSD: `関連画像並び最後尾: X (n/m)`）。
  - すでに現在の関連画像並びの**最後尾**にいる場合：**次の関連画像並びの先頭**へスキップします（OSD: `次の関連画像並び: X (n/m)`）。そのまま `Ctrl + End` を連打することで、次のグループへと次々にスキップできます。
  - フォルダー全体の最後のグループの最後尾にいる場合：`最後の関連画像並びの最後尾です: X (m/m)` と通知されます。

## 6. 最下行のシークバー（ツールバー）と全画面ポップアップ

`表示(V) -> ツールバー表示` を ON にするとウィンドウ最下行にシークバーが表示され、さらにフルスクリーン表示時には**マウスカーソルを画面下端へ移動するだけで自動的にシークバーがポップアップ表示**されます（同時に縦横スクロールバーも連動表示されます）。

- **左側ボタン群**: `フォルダツリー(フォルダを開く)` / `前のフォルダ(書庫)へ` / `前に戻る` / `再生・停止 (2.5秒スライドショー)` / `次に進む` / `次のフォルダ(書庫)へ` / `ファイルを開く` / `最初のページへ`
- **中央シークバー & ページ番号ボックス**:
  - スライダーをドラッグして任意のページへリアルタイムにシーク移動できます。
  - 右隣のページ番号ボックス（例: `12/546`）をクリックすると、ページ番号を直接数値入力してジャンプできます。
- **右側ボタン群**: `最終ページへ` / `見開き方向切替 (右開き⇔左開き)` / `ルーペ表示` / `サムネイル表示(1画面)` / `ブックリスト表示` / `フルスクリーン切替`
- **レトロ／モダンスタイル連動**:
  `表示(V) -> メニュースタイル切替`（または環境設定）で **「レトロ (MangaMeeya互換)」** と **「モダン (MangaMeYeah! ロゴカラー)」** をいつでも切り替え可能です。

## 7. Windows の拡大率（DPIスケーリング）と「原寸サイズで表示」について

Windows 11 のディスプレイ設定で「拡大縮小（例: `150%` や `175%`）」が設定されている環境において、MangaMeeya 本体はシステム DPI スケーリングの影響を受けるため、「原寸サイズで表示」を選択した際に Windows の拡大率分だけ拡大されて表示される挙動となっていました。

MangaMeYeah! では、MangaMeeya から移行した際に違和感が生じないよう、標準では **MangaMeeya と同様に Windows の拡大率（論理ピクセル DIP）を反映した「原寸サイズで表示」** を行う仕様としています。
