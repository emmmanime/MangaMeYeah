## MangaMeYeah! のコンセプトと現代化の意義

20年以上前に登場し、今なおコミック・画像ビューアーの金字塔として愛用される「MangaMeeya」ですが、現代のPC環境（Windows 10/11, 64-bit, マルチモニター, 高解像度ディスプレイ）では以下のような課題がありました：

1. **文字コード（Shift_JIS）の制約**: 絵文字や多言語、特殊な記号を含むパスでファイルが開けない・文字化けする。
2. **新世代フォーマット非対応**: WebP、AVIF、スマートフォンの HEIC、カメラRAW（DNG/CR3/ARW等）を閲覧するために別のビューアーを併用せざるを得ない。
3. **SNS特有の分割画像**: X（旧Twitter）などで1枚のイラストを2〜4分割や2×2グリッドで投稿された作品を手作業で並べ直す必要がある。
4. **macOS リソースフォーク (`__MACOSX`)**: Macで作成された Zip ファイルに不要なゴミファイルが混ざり、手動で削除・再構築が必要になる。

**MangaMeYeah!** は、MangaMeeya の比類なき操作体系（左右クリックでのページめくり、コード操作、マウスジェスチャー、ルーペ）を完全に継承しながら、現代の画像収集・閲覧ワークフローに必要な機能を .NET 8 / 64-bit WPF ネイティブで妥協なく統合した「ストイックで爆速な純粋ビューアー」です。
