# フォルダー・書庫の読み込み仕様 (Folder & Archive System)

MangaMeYeah は、通常のフォルダーだけでなく、各種書庫ファイル（Zip / CBZ / RAR / CBR / 7z）や、それらが幾重にも重なった階層構造を意識することなくシームレスに通し読みできるよう設計されています。

---

## 1. 4つの階層関係と設定の切り分け

コミックやイラストのコレクションでは、フォルダーと書庫の組み合わせとして主に以下の4つの関係が存在します。MangaMeYeah では、それぞれを以下のように取り扱います：

| 階層関係 | 構造の例 | MangaMeYeah の動作・設定 |
| :--- | :--- | :--- |
| **フォルダー内フォルダー** | `Volume1/Chapter1/01.jpg` | **サブフォルダ読み込みモード**（`環境設定 > 一般設定1`）<br>・確認ダイアログ<br>・常に読み込む（デフォルト）<br>・読み込まない |
| **フォルダー内書庫** | `Volume1/Special.zip` | **フォルダ内書庫もサブフォルダに含める**（チェックボックス）<br>ONの場合、フォルダー内のZip等もサブフォルダーの1つとして透過的に結合 |
| **書庫内フォルダー** | `Volume1.zip` 内の `Ch1/01.jpg` | 書庫の標準構造として**常に自動サポート**（展開待機ゼロ） |
| **書庫内書庫** (ネスト書庫) | `Volume1.zip` 内の `Bonus.cbz` | **書庫内書庫もサブフォルダに含める**（チェックボックス）<br>ONの場合、一時ファイルをディスクに書き出すことなくメモリ上で直接展開 |

---

## 2. 並列（兄弟）フォルダーの自動切り替え仕様

### なぜ「並列フォルダー」は一度に読み込まないのか？
例えばある作品フォルダーの下に `第1巻` 〜 `第50巻` のフォルダーが並んでいる場合、`第1巻` を開いたときに `第2巻`〜`第50巻` の全画像（数万枚）を一斉に1つのタイムラインに読み込んでしまうと、起動が極めて重くなる上、「巻ごとに読む」「最後に読んだ巻を記憶する」という体験が破綻してしまいます。

そのため、MangaMeeya および MangaMeYeah では：
1. **フォルダーを開いた時点**: そのフォルダー（および配下のサブフォルダー）の画像のみを読み込みます。
2. **最終ページに到達した時点**: 左クリックまたは `Next` で、**自動的に次の並列（兄弟）フォルダーへスムーズに遷移** します。
3. **先頭ページで戻った時点**: 右クリックまたは `Prev` で、前の並列フォルダーの最終ページへスムーズに移行します。

### バックグラウンド先行探索による 0ms 移行
最終ページ到達時にスムーズに次のフォルダーへ移れるよう、MangaMeYeah はフォルダーを開いた段階でバックグラウンドスレッドが「次のフォルダー」「前のフォルダー」を先行探索してキャッシュしています。そのため、巻末でのクリック時にディスク読み込みの引っかかりを起こさず、瞬時に次の巻へ移ることができます。

## 3. MangaMeYeah式 階層自然順グループソート

フォルダー内に表紙画像（`Cover.jpg`）と、各章のサブフォルダー（`Chapter 1`, `Chapter 2`...）や書庫ファイルが混在している場合、単純に全ファイル名だけでソートしてしまうと、異なる章の `01.jpg` 同士が互い違いに入り乱れてしまいます。

MangaMeYeah では、以下のルールで美しくグループ化して並べます：

```
[親フォルダー]
 ├─ Cover.jpg                ← ① 親フォルダー直下の画像が必ず先頭に来る
 ├─ Chapter 1/               ← ② サブフォルダーや書庫が自然順（1, 2, 10...）で並ぶ
 │   ├─ 01.jpg               ← ③ 各フォルダー内のファイル順序が保たれる
 │   └─ 02.jpg
 ├─ Chapter 2/
 │   ├─ 01.jpg
 │   └─ 02.jpg
 └─ Chapter 3.zip            ← ④ フォルダー内書庫も同等に自然順でシームレスに結合
     ├─ 01.jpg
     └─ 02.jpg
```

閲覧中にメニューからファイルソート（名前順、更新日時順、ファイルサイズ順等）を変更した場合でも、この階層グループ構造が常に維持されます。

---

## 4. macOS リソースフォーク (`__MACOSX`) の自動無視

Mac で圧縮された Zip ファイルには、各画像に対応したメタデータファイル（`._filename.jpg`）や `__MACOSX` という隠しフォルダーが自動混入することがあります。  
MangaMeYeah はこれらのシステム管理ファイルを完全に無視・除外して読み込むため、ユーザーが手動で書庫を解凍・再圧縮してゴミファイルを掃除する必要は一切ありません。
