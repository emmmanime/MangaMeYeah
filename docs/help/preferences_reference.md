# 環境設定リファレンス (Preferences Reference)

メニューの `設定(S) > 環境設定(C)...` で表示される各設定項目の詳細な説明です。

---

## 1. 操作設定 (Tab 1)

MangaMeeya の操作感や移動量を好みに合わせてカスタマイズできます。

- **ズームステップ (%)**: 拡大・縮小時の1ステップあたりの倍率変化量（デフォルト: 5%）。
- **倍率固定 (デフォルト)**: 「倍率固定」スケールモード時の拡大率（デフォルト: 125%）。
- **指定スケール**: 「指定スケール」スケールモード時の拡大率（デフォルト: 170%）。
- **同じモードでスケールリセット**: 現在と同じスケールモードを選んだ際、倍率をデフォルト（100%）にリセットするかどうか。
- **次のページ/前のページ ステップ数**: クリック時の基本移動ページ数（デフォルト: 1）。
- **PageDown/Up ステップ数**: PageDown / PageUp キー押下時の移動ページ数（デフォルト: 10）。
- **ドラッグスクロール量 (pixel)**: マウスドラッグ時のスクロール感度（デフォルト: 1）。
- **スクロール単位**: キーボードやホイールによる画像スクロールの計算基準（ウインドウサイズ / 画像サイズ / 固定値）。

---

## 2. 一般設定 1 (Tab 2)

フォルダーの読み込み動作や、見開きの表紙表示に関する設定です。

- **サブフォルダ読み込み**:
  - `ダイアログで確認`: サブフォルダーや書庫が存在する場合に読み込むか確認ダイアログを表示。
  - `常にサブフォルダも読み込む`: 自動的に配下の全画像・書庫を含めて通しで読み込み（★推奨）。
  - `サブフォルダは読み込まない`: 選択したフォルダー直下の画像のみを読み込み。
- **フォルダ内書庫もサブフォルダに含める**:
  フォルダー閲覧時に、同階層やサブフォルダー内にある書庫ファイル（`.zip`, `.rar` 等）もサブフォルダーの1つとして透過的に結合して読み込みます。
- **書庫内書庫もサブフォルダに含める**:
  書庫ファイルの中にさらに格納されているネスト書庫（`.zip` 内の `.cbz` 等）を直接展開して読み込み対象に含めます。
- **先頭に白紙ページを挿入する**:
  見開き表示時、表紙（1枚目）を単独表示にし、2枚目以降を本来の見開きペアとして揃えるための白紙挿入設定です。

---

## 3. 一般設定 2 (Tab 3)

ルーペ（拡大鏡）および背景色に関する設定です。

- **ルーペ半径 / 拡大率**: ルーペの直径サイズ（デフォルト: 140px）および部分拡大率（デフォルト: 2.0倍）。
- **ルーペ形状**: 円形ルーペ または 四角形ルーペ の選択。
- **枠線表示 / 画面内に制限**: ルーペの外枠表示、および画面外への見切れ防止。
- **ルーペ使用時、メニュー、ツールバーのポップ表示抑制**:
  ルーペ使用中に画面上端付近へカーソルを寄せても、メニューバー等の意図しないポップアップを抑制します（★推奨）。
- **背景設定 / 本棚背景設定**:
  メインビューワーの余白背景色、およびライトテーブル（サムネイル一覧）の背景色。右側の「色選択...」ボタンでWindows標準カラーパレットから直感的に指定可能です。

---

## 4. その他設定 (Tab 4)

ウィンドウ挙動やシステム連携に関する設定です。

- **複数起動を禁止する**:
  ON にすると、エクスプローラー等から別の画像を開いた際に新しいウィンドウを作らず、既存の MangaMeYeah ウィンドウにファイルを転送して最前面化します。
- **終了時のウィンドウ位置を記憶する**:
  終了時のウィンドウサイズおよび位置（モニター座標）を次回起動時に忠実に復元します。
- **起動時に最後に開いていたファイルを開く**:
  起動時に前回読んでいたフォルダーや書庫の続きから即座に再開します。
- **フルスクリーンのマウスカーソル自動非表示 / 常に最前面表示**:
  動画や読書に集中するためのカーソル隠蔽や最前面ピン留め設定。

---

## 5. キャッシュ設定 (Tab 5)

メモリ使用量と先読み速度のバランスを調整する設定です。

- **展開キャッシュ数**: デコード済みビットマップを保持する枚数（デフォルト: 32枚）。
- **リサイズキャッシュ有効**: ディスプレイ解像度に合わせて縮小したビットマップをキャッシュし、メモリと描画負荷を削減（デフォルト: ON）。
- **先読み数 (進む方向 / 戻る方向)**: バックグラウンドで先読みデコードしておく枚数（デフォルト: 各4〜6枚）。※自動連結画像検出には進む方向4枚以上を推奨。
- **先読みスレッド優先度**:
  - `最低`: UIスレッドへの干渉を極限まで低減（省電力PC向け）
  - `通常`: 標準マルチコアPCに最適なバランス（★デフォルト）
  - `最高`: 次ページを最速で先読み
- **キャッシュ制限容量 (MB)**: キャッシュの合計メモリ上限（デフォルト: 2048 MB）。
